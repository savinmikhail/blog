# Воспроизводимые опыты

Проверено 16 октября 2026 на macOS. Все значения искусственные. Скрипты именно этого каталога не запускают контейнеры; Docker здесь используется только для `compose config`. Отдельный выполненный runtime-опыт находится в [example/](../example/README.md).

## Запуск

В отдельной копии этого каталога, с установленными Python >=3.11 (format-probe использует tomllib), Node (поддерживающим --env-file), Bash, GNU Make и Docker Compose:

```sh
python3 probe.py
python3 leak-probe.py
```

Скрипты перезаписывают только тестовые fixtures и JSON-результаты в своём каталоге. `probe.py` сравнивает три поля одного файла и два варианта Compose precedence. `leak-probe.py` проверяет присутствие dummy-секрета в resolved config и чтение владельцем файла с правами 0600. Не подставляйте настоящие секреты.

`results.json` и `leak-results.json` — фактический вывод локального запуска. PID в результате Bash и абсолютный путь в secret definition будут отличаться. Версии инструментов сохранены в results.json. Python при запуске: 3.14.8.

## Границы выводов

- Compose config — сериализованная модель, не результат чтения окружения контейнера. Вывод $$ может быть экранированием сериализатора.
- Не проверены Docker inspect, фактические mount permissions, Linux другой UID, Kubernetes и политики AI-агентов.
- chmod 600 проверяется от владельца: это не тест запрета другим пользователям.
- Fixtures намеренно простые; отсутствие расхождений для них не доказывает совместимость всех грамматик dotenv.

## Дополнение: форматы и выполнение

`python3 format-probe.py` проверяет дубликаты ключей Python JSON/TOML и сравнивает Bash source с Node --env-file на `$(printf synthetic-command-ran)`. Сетевых обращений и реальных секретов нет. Fixture создаётся во временном каталоге и удаляется; результат записывается рядом со скриптом. Этот опыт выполнен с Node 24.20.0 (первый probe — с Node 26.10.0); версии сохранены отдельно в format-results.json. Уязвимые версии пакетов и CVE не эксплуатировались.
