## Замечания по важности

### [P2] Укажите исполнение `$()` именно в Symfony Dotenv

Место: `env-article.md:250-254`, особенно цитата «Даже специализированный loader может поддерживать исполнение: dotenvx документирует command substitution».

В основной PHP-экосистеме статьи это поддерживает и Symfony Dotenv: `resolveCommands()` в установленном 7.4.18 вызывает `Process::fromShellCommandline(...)`, если установлен `symfony/process`, платформа Unix и значение не защищено literal-кавычками/экранированием. Документация Symfony прямо показывает `START_TIME=$(date)`. В текущем минимальном примере symfony/process не установлен: безопасная проверка parse вернула LogicException «Resolving commands requires the Symfony Process component».

Почему важно: читатель может заменить source специализированным Symfony-loader и решить, что исключил выполнение команд. Общая оговорка про другой инструмент недостаточно ясно объясняет риск основного рекомендованного стека.

Минимальное исправление: добавить в §8 2–3 предложения про Symfony, Unix и зависимость symfony/process; назвать allowlisted data-only loader / проверку реально включённых возможностей. Не объявлять этот опыт исполненным в текущем примере, где Process отсутствует.

Источники:
- https://symfony.com/doc/current/configuration.html#env-file-syntax — пример `$()`.
- `/private/tmp/env-guide-example/vendor/symfony/dotenv/Dotenv.php:529-568` — условия и исполнение.

### [P2] Раздел синтаксиса перечисляет вопросы, но не учит их решать

Место: `env-article.md:87-124`, в частности строка 108: «Перед переносом файла проверьте хотя бы кавычки, #, $, пустые значения и многострочный текст».

В принятом плане §4 обещает правила кавычек, пробелов, комментариев, multiline и спецсимволов. Сейчас реально разобраны только `${BASE}`, `$$` и URL encoding. Не показано, как записать literal пароль с `$`/`#`, чем отличаются single/double quotes, `KEY=` и bare `KEY`, какие правила относятся к Symfony и какие к Compose. Для читателя со сломанным паролем рекомендация «проверьте» не закрывает вопрос.

Минимальное исправление: добавить 6–8 строк таблицы поведения одного выбранного загрузчика (Symfony) с искусственными примерами; рядом отдельная колонка/оговорка различий Compose и Node. Включить хотя бы одиночные кавычки literal, двойные с expansion, inline comment, пустое/отсутствующее значение и multiline либо file transport. Подтвердить именно установленной версией и не выдавать за общий dotenv-стандарт.

Источники:
- https://symfony.com/doc/current/configuration.html#env-file-syntax
- https://docs.docker.com/compose/how-tos/environment-variables/variable-interpolation/#env-file-syntax

## Дополнительная проверка интерполяции и минимальная таблица синтаксиса

Получил уточнение автора о Symfony 7.4.18, затем **независимо повторил** `php /private/tmp/env-guide-example/dotenv-probe.php`. Результат: base `ENV_GUIDE_HOST=base`, `ENV_GUIDE_URL="https://${ENV_GUIDE_HOST}/path"`, затем `.env.local` с HOST=local → итоговый URL=https://local/path. В 7.4.18 `loadEnv()` откладывает раскрытие до загрузки слоёв (см. deferPutenv/resolveLoadedVars в коде). Поэтому пример stale-derived-value нельзя переносить с Python dictionary merge на этот Symfony loader. Исходный проверенный снимок статьи формулировал это условно и показывал именно Python — это корректно. Любую позднюю вставку с противоположным Symfony-результатом нужно удалить до публикации.

Отдельно выполнил `Dotenv::parse()` на Symfony 7.4.18 для безопасных искусственных строк. Минимальная таблица для §4:

| Исходник Symfony dotenv | Полученное значение / результат |
|---|---|
| `VALUE='p@ss#w$rd'` | literal `p@ss#w$rd` |
| `ENV_GUIDE_A=alpha`, затем `VALUE="${ENV_GUIDE_A}#tail"` | `alpha#tail` |
| `VALUE=alpha # comment` | `alpha` |
| `VALUE=alpha#tail` | `alpha#tail` |
| `VALUE=` | пустая строка |
| `VALUE` без `=` | FormatException |
| `VALUE="first\nsecond"` с backslash+n | настоящее LF между first и second |
| те же два слова с настоящим LF внутри double quotes | настоящее LF, multiline поддержан |
| `VALUE =alpha` | FormatException: пробел после имени не допускается |

Это результаты конкретной версии PHP-компонента. Не использовать их как универсальные правила Bash, Make, Node или Compose. Желательно сохранить маленький probe рядом с примером, если таблица попадёт в статью; автор основного потока должен добавить его сам, я файлы примера не менял.
