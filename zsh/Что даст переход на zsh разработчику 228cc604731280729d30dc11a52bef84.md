# Что даст переход на zsh разработчику?

[Zsh](https://www.zsh.org/) это командная оболочка, то есть утилита, которая получает от пользователя команду в текстовом виде и выполняет соответствующие бинарники, зарегистрированные через PATH как правило

Zsh является дефолтной оболочкой для macos, на linux дефолт - bash. Zsh лучше,  чем bash в основном благодаря своей очень обширной системе плагинов, модулей, тем (и не только)

Например установив вот такой плагин

```bash
brew install zsh-autosuggestions
```

и включив его через добавление в ~/.zshrc строки

```bash
source /opt/homebrew/share/zsh-autosuggestions/zsh-autosuggestions.zsh
```

я получаю автокомплит в терминале, подобный автокомплиту когда пишешь код в PHPStorm с автокомплитом

![image.png](%D0%A7%D1%82%D0%BE%20%D0%B4%D0%B0%D1%81%D1%82%20%D0%BF%D0%B5%D1%80%D0%B5%D1%85%D0%BE%D0%B4%20%D0%BD%D0%B0%20zsh%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D1%83%20228cc604731280729d30dc11a52bef84/image.png)

Автокомплит основан на истории ваших запросов (можно посмотреть через `history`, например), из-за чего может подсказывать и неверные команды. То есть это не AI какой-нибудь, а скорее

```bash
history | grep <your prompt> 
```

Поэтому вы можете хотеть понастраивать хранение истории, например 

```bash
#  History
# хранить историю в указанном файле
export HISTFILE=~/.zsh_history
# максимальное число команд, хранимых в сеансе
export HISTSIZE=1000
export SAVEHIST=$HISTSIZE
# включить историю команд
setopt APPEND_HISTORY
# убрать повторяющиеся команды, пустые строки и пр.
setopt HIST_IGNORE_ALL_DUPS
setopt HIST_IGNORE_SPACE
setopt HIST_REDUCE_BLANKS
```

Zsh стоит ставить сразу вместе с Oh-my-zsh. Это своего рода менеджер плагинов

Например, у меня в ~/.zshrc прописаны следующие плагины:

```bash
plugins=(git composer symfony6 docker docker-compose)
```

Замечу, что `git` по умолчанию включен, а остальные уже я ручками добавил. Для laravel тоже есть плагин, просто я не пишу на ларе

Давайте разберем, какую именно пользу можно из них почерпнуть

1. [git](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/git#aliases)
    
    Регистрирует в оболочке большущий сет алиасов и функций. То что я запомнил и использую -
    
    - `gl` вместо `git pull`
      - `gp` вместо `git push`
      - `gcb` вместо `git checkout -b`
    
    На отображение текущей ветки в терминале наличие этого плагина не влияет (зато установленная тема может повлиять)

   ![image.png](%D0%A7%D1%82%D0%BE%20%D0%B4%D0%B0%D1%81%D1%82%20%D0%BF%D0%B5%D1%80%D0%B5%D1%85%D0%BE%D0%B4%20%D0%BD%D0%B0%20zsh%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D1%83%20228cc604731280729d30dc11a52bef84/image%203.png)

2. [composer](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/composer)
    
    Все что делает, это регистрирует свои алиасы. Из полезного imho:
    
    - `c` вместо `composer`
    - `ci` вместо `composer install`
    - `cu` вместо `composer update`
    
    Вижу что подобные алиасы разработчики часто сами регистрируют, но можно унифицироваться через такой плагин
    
3. Остальные плагины делают ровно то же самое, найти списки их алиасов можно в том же репозитории

На именно такое отображение промпта оболочки влияют темы

![image.png](%D0%A7%D1%82%D0%BE%20%D0%B4%D0%B0%D1%81%D1%82%20%D0%BF%D0%B5%D1%80%D0%B5%D1%85%D0%BE%D0%B4%20%D0%BD%D0%B0%20zsh%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D1%87%D0%B8%D0%BA%D1%83%20228cc604731280729d30dc11a52bef84/image%204.png)

Самой известной является `powerlevel10k`, после установки она запустит свой wizard, в котором вы сможете настроить отображение промпта по шагам

Единственное, я бы рекомендовал, если ваш терминал отображает весь путь к текущей папке от домашней директории, поставить в конфиг файле `~/.p10k.zsh` опцию `POWERLEVEL9K_SHORTEN_STRATEGY` в значение `truncate_to_last`, будет отображать только название папки в которой находитесь

Подводя итоги - автокомплит и алиасы здорово экономят время и нервы (вас же тоже бесит печатать `docker compose blablabla` ?). Вдобавок zsh красивее, чем bash, и чем-то неуловимо приятнее
